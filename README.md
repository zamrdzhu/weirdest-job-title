One original job title for make.fun's "Weirdest Job Title: Blind Judge Showdown" — a real job with one gloriously specific twist: a dog walker whose clients are all cats. Picture it: one person in the park, six cats on leashes, each going a different way.

> Dog Walker (Cats Only)

## Run it

```sh
node main.ts
```

The program prints the title and writes the same line to `/output/entry.txt` (22 characters, inside the 60-character gate). It is fully deterministic: run it twice and the output is byte-identical both times.
